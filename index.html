JSON Studio – View, Edit & PDF

A simple JSON tool for Android.

JSON Studio helps you view, create, edit, format, validate, search, manage, and export JSON files directly on your Android device.

  • View JSON files
  • Create JSON
  • Edit JSON
  • Format & beautify JSON
  • Validate JSON
  • Search JSON content
  • Save & manage files
  • File history
  • Export JSON to PDF
  • Support for large JSON files
