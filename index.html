JSON Studio – View, Edit & PDF

JSON Studio is a simple Android app for viewing, creating, editing, formatting, validating, managing, and exporting JSON files.

Features

  • View JSON files
  • Create JSON
  • Edit JSON
  • Format and beautify JSON
  • Validate JSON
  • Search JSON content
  • Save and manage files
  • File history
  • Export JSON to PDF
  • Support for large JSON files

Get JSON Studio on Google Play
